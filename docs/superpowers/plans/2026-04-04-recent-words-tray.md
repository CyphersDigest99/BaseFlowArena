# Recent Words Tray Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a stable pill tray to the bottom of the Live Feed panel showing the last 20 unique spoken content words — clickable to set as active word.

**Architecture:** New `state.recentWords[]` array feeds a `updateRecentWordsTray()` renderer in `ui.js`. The renderer is called on every final STT result alongside the existing `updateTranscript` logic. A delegated click handler in `main.js` wires the pills to `setActiveWord()`. No new files needed.

**Tech Stack:** Vanilla JS ES modules, HTML5, CSS3. No test framework — verify manually with `python3 server.py` at http://localhost:8000.

- [ ] **Step 2: Add `updateRecentWordsTray()` export**

Add this function after `clearTranscript()` (after line 591 in current file):

```js
// Renders the recent-words pill tray from state.recentWords
export function updateRecentWordsTray() {
    const tray = document.getElementById('recent-words-tray');
    if (!tray) return;
    if (!state.recentWords.length) {
        tray.style.display = 'none';
        return;
    }
    tray.style.display = 'flex';
    tray.innerHTML = '';
    state.recentWords.forEach(word => {
        const pill = document.createElement('span');
        pill.className = 'recent-word-pill';
        pill.textContent = word;
        if (word === state.transcriptSelectedWord) {
            pill.classList.add('selected');
        }
        tray.appendChild(pill);
    });
}
```
